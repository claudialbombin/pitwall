Interactive gallery

THE GARAGE

Four hand-built, fully animated F1 illustrations — pick a scenario, control the playback, and hover a part to see it highlighted. Everything here is a single self-contained SVG: no video, no canvas, just CSS keyframes.

Speed

Pit stop — side view. Jack goes in, gun off, wheel swap, gun on, lollipop up, launch. Six-second loop, timed like a real 2.3s stop.

Wheel change

Side and top views of the same four-tyre change, choreographed against a realistic ~2.3s stationary time.

Passing & arriving

The launch phase of the pit-stop clips and the flat-out fly-by cover the car arriving, passing, and leaving.

Turning & drifting

The corner sequence pushes the rear tyres past the limit — steering angle, tyre smoke, and fading skid marks.

Built for the README

Every clip here is the exact SVG embedded in the project README — it animates the same way on GitHub.
